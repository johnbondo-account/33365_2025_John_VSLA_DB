# SQL Execution Screenshots

This folder contains screenshots captured during the development, testing, and verification of the **Village Savings and Loan Association (VSLA) Database Management System** implemented using **Oracle Database XE 21c** and **Oracle SQL Developer**.

The screenshots provide visual evidence that every SQL script in the project was successfully executed and verified. They demonstrate database creation, data population, PL/SQL programming, triggers, security controls, reporting, and final system validation.
